## Reference Responsibility Audit（继承 C15）

肖像仅提供被批准的人物身份：脸形比例、可确认毛发/发际线、体型和辨识细节。当前姿态/站位/视线归 Blocking；表情与紧张归 Performance；光照和镜头归既有专业 owner。A 的三区/参考可见性说明提供细化语言，B 的 edit target 不变原则只对局部编辑适用，D 支持肖像不带姿态/照明但让 scene reference 带表演的默认与平台冲突。

可靠性限定：来源中的职责文字是意图约束，没有提供可靠自动分离像素层的方法。不同光线、角度、表情和遮挡会影响可读结构；参考只见一面不能确定背面/隐藏发际线，合成多角度也不是独立真值。生成结果不得未经重新批准替代原身份锚点。

A3 D2 professional_sources 仍是提案；本轮源码 FrameSpec 没有这个字段，不能把它写成当前能力或提前扩展。C15 若进 Face A3，只需审查面部身份子职责、证据可见性和阶段边界的细化，不推翻 stable identity != current shot state。

## 额外的真实代码边界

`validate_assets` 把 AssetDecision.source_refs 限定到该资产 Director、Dramaturgy、Source/World 的原件 pins，且必须包含自身 Dramaturgy。外部知识、Casting 结果或本轮报告不能直接塞进这一白名单；未来如何保持批准设计的来源链需 Face A3 再判断，本轮不设计新字段或绕过规则。

image_serializer 的编辑选择器保留 face/role/costume 等行，age/hair/visible_condition 并非逐条默认重述，而是依编辑原图和明确 preserve。它已有“除指定变化外保留原图”的约束，但不能据此声称每个年龄/发际线细项都有独立核验。该观察是 F31/F37/F40 的消费链证据，不是本轮提出修改 serializer。正常静态生成会输出各 subject facts。
