## 为什么语义正确仍有问题

当前第一句已经完成核心情境说明；之后才出现男人真正听、女孩误判跟随、撤手、再次阻离。这使开场的观看任务较快转为“他为什么拒绝已经明确的求助”，而用户希望首先经历“一个封闭的人怎样被另一个人的要求打断”。

前者并非普遍无效，但与本轮明确要求的经验过程有偏差。旧版 Director S02 意图强调拒绝需要主动用力、女孩不是唤醒主人公的符号；R2 后半场保留了这种努力，却没有独立审阅首轮信息是否抢在关系压力之前。

不能说女孩完全没先尝试：拉手肘和停脚已经发生。更精确的缺口是：这次部分成功/未获参与，尚未被充分组织为一次可辨认的反馈与策略改变，完整信息就全部释放。也不能说后面没有 failure/escalation；T05–T11 明确有。审计修复层应是 Scene 的开场过程/信息组织与 DPD 交接，而非对单句再做润色。

## 现有检查为何允许这一点

- literal clarity Gate 能检查请求可理解，不能评价出现时间。
- action carrier Gate 能检查拉、转、收、抓存在，不能证明相互因果和顺序。
- B02 场景级 audience_knowledge 能限制不揭示母亲结局，不能限制首句释放量。
- 当前 R2 actor beats 与 reaction witness 的粒度/时序不足，详见表演审计。
- Prompt semantic coverage 只能忠实保存这些已批准事实；不能代补前置失败或猜新台词。

这些不是“再增加一个 emotion 字段”可解的问题。

## S01 / S03 supporting diagnostics

**S01**：男人在被追问后不回答，离开并非被驱赶；楼梯停听而无人叫他，把“退出”与“是否被需要”置于张力中。停顿有关系功能，不能作为无用镜头自动剪去。Director 可强调其未获回应的体验，DPD 须支持男人的任务解释；不能补别人挽留来把意图讲明。

**S03**：袖褶接回女孩，手的中止动作、自辩、咳嗽、门把前停住，把抽象无关论逐步带回具体邻人。邻门母亲不是女孩母亲，不能混淆两条来源。现有正文已有压力推进；审阅重点是每一步是触发/抵抗/后果还是只被附录解释成象征，以及表演指导是否保留反复接近又退缩的差别。不能为了“更有戏”在本轮新增开门、照料或对白。
