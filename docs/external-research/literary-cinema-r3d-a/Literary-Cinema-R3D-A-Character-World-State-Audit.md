## Ownership 裁决

Character Existential State 由 **Character Dramaturgy** 拥有，作为既有 CharacterArcState 在具体阶段的内容，不另建人格/诊断实体。belief、relationship、behavioral、narrative state 已能表达大部分；不足是证据限定与下游具体适用范围。Character External Driver 在批准后固化为可携带 package；Embodiment 产生有条件的身体观察；DPD 定义当场任务/策略；Performance/Voice 实现；Director选观众重点。

Character ↔ World Relation 的**人物一侧关系命题**仍由 Character Dramaturgy 拥有（relationship/belief state）；Scene 拥有当场事件和变化；**观众如何经验这种主客观差异**归 Director 的现有 intent。这里划开两种不同值，不采用多人共写同一 `world_relation`。World/Source 只拥有地点、天气、生活事件等事实，Specialized Asset 实现环境，Production Design审一致性，不定义他的心理。

## Costume / Appearance / Face / Body 交接

现行 Specialized Asset 明确要求 character_ref、arc_stage、behavior_pattern、social_position，并 pin Director/Source/World；不是只核时代服装。现行 Embodiment 已要求内因→有条件的观察、稳定倾向与阶段变化、源 pointer/hash，禁止以职业或人格推定解剖。

本片可交给资产部门的问题是：哪些社会处境与生活惯例有证据？哪些维护行为未说明？状态变化是否要求连续性判断？答案目前包括贫困、受教育、昼读夜坐；不包括“曾经很体面”“已经不洗衣”“恒常驼背”。没有 source 的项目保持 UNSPECIFIED，不能以“人物虚无”自动填满。

脸部骨骼/体型属于稳定外观，当前目光与动作能量属于 Performance，暂时疲劳/脏污属于 Look，稳定有条件的习惯属于 Embodiment。对同一部位有不同层次的 owner 不等于竞争作者：资产不能用脸定义信念，DPD不能把这一场疲惫永久写成 Character Core。S02用力斥退和S14狂喜已直接反对“全程麻木脸”的模板。

## REALITY_DREAM_RELATION_AUDIT

| 维度 | 现实 / 梦 / 返回 | 必须保留的复杂性 |
|---|---|---|
| 人物关系 | 现实拒绝；梦接纳又分裂；醒后主动接触 | 现实别人仍有自主生活，梦群众亦能拒绝他 |
| 参与程度 | 在场不参与→加入→控制/破坏→接受具体请求 | 不是从0到1的道德仪表 |
| 触碰 | 女孩抓肘A006；居民亲吻拥抱A028；求刑伸手A038 | 袖褶与门的精细回声主要是电影发明 |
| 声音 | 笑、求助、喧声；互唱自然与彼此→歌颂苦难；传讲被笑 | A039醒来反而少见寂静；不能“重新参与=处处更吵” |
| 空间 | 城市/租屋；墓中束缚、太空、海岸、分裂社会；同一旧椅 | 主观空间不能证明客观宇宙；也不只是暗/亮美术两套 |
| 死亡 | 现实未开枪；梦枪/墓；共同体老人死亡；再次求死；醒来生 | 乐园有死亡，选择活时天未亮 |
| 社会/自然 | 原街稀少行人、邻人惧上尉；梦自然亲近、后动物离去 | “世界正常运行”只指不以主人公为中心，不指社会无苦难/暴力 |

A004有阴郁雨夜与灯光使他更难受的直接描写；不应为反对黑暗模板而删掉它。A028有晴日明亮，同样可保留。但A018梦也极黑，A039现实希望转折尚未天亮；不足以支持 REALITY=DARK / DREAM=BRIGHT 的全片法则。Lighting/Color须继承这种时段和关系限定。
