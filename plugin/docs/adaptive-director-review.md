# Adaptive director review

Use existing Director request/feedback, FilmReview/FilmFinding and EditorialUsability.
The optional FilmReview `observedMaterialEvidence` and `adaptiveDecisions` facets
keep the same review owner. The six small contracts in contracts.adaptive_direction
separate evidence, deviation, performance delta, surprise, impact and decision.
Existing AestheticPairwiseReviewContract owns pairwise comparison and work-scoped
explicit user feedback. No universal director state machine or new provider exists.

## Intended, observed, judged

Before live review, Host resolves Media → formal Shot → coverage realization →
Director intent → Scene and calls the existing media lineage gate. Then
`authorize_observation` requires current priority/cut/continuity/performance/film
 grammar/aesthetic/music/history/runtime/intent pins and an independently verified
semantic runtime receipt. Capabilities are Host attestations, not auto-discovery.
Missing trace is R5C_OBSERVATION_NOT_AUTHORIZED; missing semantic runtime is
MEDIA_SEMANTIC_OBSERVATION_GAP. Current bytes and full-byte hashes remain the Host's
responsibility. Approval/readiness does not authorize generation or spend.

ObservedMaterialEvidence holds falsifiable facts, range, evidence/source hashes,
method, factuality review, observer and confidence. Facts use visible action,
position, contact and ordering, not quality or psychology. Unknown is explicit and
blocks dependent decisions. Technical metadata is limited to technical artifacts;
frames cannot prove temporal order or sound, and audio cannot prove visible action.
A narrow lexical guard catches obvious category mistakes; it cannot certify the
semantics of arbitrary language. A human or verified observer must review facts.
Confidence concerns factual certainty, never an aesthetic score.

STRUCTURED_FIXTURE has isolated identities and cannot become OBSERVED_MEDIA.
Fixture receipts and decisions explicitly stay dry-run. FilmReview requires matching
playback/ranges for live facts; its summary flags pending adaptive authority review,
not user adoption. Actual observer evidence is still necessary; none of these
functions watches video, listens, or infers performance from ffprobe.

## Compare and preserve

`adaptive_review` binds exact evidence, intended pins and existing Dailies usability.
Classify MATCH / ACCEPTABLE_VARIATION / MATERIAL_DEVIATION /
POSITIVE_SURPRISE_CANDIDATE / OBSERVATION_UNCERTAIN by domain. Provider artifacts
are separate from acting. Keep artistic judgment qualitative and distinct from
USABLE_FULL / USABLE_PARTIAL / EDITORIAL_REPAIRABLE / NEEDS_PICKUP / UNUSABLE.

Ask first whether existing editing can repair the problem. Before escalation,
explain why lower-cost alternatives are insufficient. Preserve good fragments,
identity, native voice, body action and useful accidents where supported. A retake
names the failed intent and minimal range; a reject explains why no fragment can
be retained and cannot contradict declared usable ranges or covered requirements. Technical retries remain in the Provider/Tool adapter; artistic
retakes are source-bound Director proposals, never automatic API retry loops.

PerformanceRedirection references actual evidence and a performance deviation,
retains known good behavior and states the smallest observable change. Do not
replace source DPD psychology, fill UNSPECIFIED, or paste the review into a provider
prompt. Hand the delta to existing cinematic-direction/shot-design, preserving the
same source-bound execution spec, then use model-selection and the existing adapter.

## Authority and surprise

P0 is always blocked for human/upstream review. P1 requires explicit review. P2
needs a grammar-equivalence rationale. P3 bounded repair may be proposed in existing
scope; proposal readiness never means permission to render or spend. ROUTE_CHANGE
needs current model-selection authority. UPSTREAM_REWRITE remains human review.

KEEP_SURPRISE requires every surprise boundary PASS with a reason, editorial
usability and complete downstream impact. Candidate cannot bypass this by using
plain KEEP. Check provenance, arc, priority, character behavior, grammar, editorial,
prop/costume/injury/position/knowledge/relationship, runtime and music/sound. Beauty
alone is not added character/action value. Unknown is not PASS.

ADAPT_DOWNSTREAM additionally resolves the retained KEEP_SURPRISE decision and its
fingerprint. Use AdaptiveDownstreamImpact as a source-pinned future overlay, with
all dimensions explicitly checked, preserving base authority and current useful
media. `downstream_overlay_handoff` requires exact reviewed decision identity and
returns an overlay candidate with writes=0. Existing Director artifact revision /
expected-head semantics retain it after appropriate review. Never rewrite historical
truth, overwrite the base, or regenerate good past material merely for uniformity.

## Pairwise and feedback

`pairwise_handoff` compares same Coverage/Intent/Scene, exact media hashes, evidence
and constitution. Per-candidate risks and performance/camera/sound differences are
explicit. Technical beauty can lose to causal clarity or reception. Reason names
the lost relation; no single beauty score. `userPreference` remains UNSPECIFIED
until an actual user feedback source, reason and constitution-rule refs exist.
Store feedback only with workId; it is a record, not model learning or global taste.

## Reachability

The Host invokes these pure gates from existing Skill entrypoints and returns
source-bound results as CapabilityFeedback evidence. FilmReview owns observation
and judgment; DirectorWorkspace retains request/review/overlay lineage. A live
adaptive proposal still needs Director authority disposition and existing full AV
review before a new reviewed/adopted revision. Skills do not auto-call providers.
Local repair executability must be checked: existing ambience/trim paths exist;
unsupported crop, speed or visual patch is not silently represented as executed.
