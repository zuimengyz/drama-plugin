# Story peaks, coverage and picture editing

The existing screenplay/incubation/adaptation/Episode/Scene owners author
DramaticPeakMap. It pins current Canon and separates CURRENT from RECOMMENDED.
Micro, Scene and Episode are review levels, never quotas. A meaningful peak has
setup, pressure, trigger, earned payoff, aftermath and character consequence.
PressureRelease can withhold release when the next passage is named by its reason.
Do not make every scene equally loud or pretend a plot waypoint is a payoff.

SetPiece is a local description, not an entity: memory purpose, pressure ladder,
first reveal, irreversible action and aftermath. HeroMoment may be a refusal,
responsibility or silence; it must be earned, change others/space and carry cost.
Do not invent causal acts to make a hero impressive. Review dynamic range, which
5–30 second excerpt a viewer might remember, what remains if the strongest30
seconds are removed, and whether visual power has been earned. No memory excerpt
is WARN/REVISE, not an automatic failure or a demand to insert a battle.

Scene owns starting pressure, escalation, turn, release and aftermath. Scene and
production-design jointly plan first appearance: silhouette, costume/blocking/
light/camera hierarchy, surrounding reaction, first readable action/attitude and
whether a caption is needed. Assign first-appearance salience from the approved character function; an ordinary
ensemble member need not receive heroic distinction. Hidden identity is one possible
reason for reduced emphasis, not the only legitimate one. Shot owns the actual framing and the cost of each attention shift.

Shot-design authors EditorialRhythmPlan: information beats, cut motivation,
reaction/detail/establishing needs, earned HeroShot, pace changes and hold reasons.
Every retained cut should change information, emotion, viewpoint or spatial relation;
otherwise merge/delete/reconsider coverage. A10s+ shot with multiple focus changes
requires SingleTakeFeasibility (YES/NO/CONDITIONAL with staging or an alternative).
Duration comes from dramatic information and later measured performance, never a
model maximum. A long single take is valid when blocking/focus can carry its changes.

Set pieces account for setup, escalation, reaction, payoff and aftermath
coverage. Hero coverage is optional and requires the Work to call for it; a shot may serve several functions. ReactionChain records actual action
and how others respond, not automatic mass cheering. Review shot-size, movement,
light, space, subject and silence/noise contrasts. Not every function needs its own
shot. Check overload, gratuitous cuts, missing reactions/details/navigation and
long periods without new visual information.

Finishing authors PictureEditPlan only after actual Media performance review.
Sources pin Media ID/hash/measured duration; sourceIn/sourceOut select useful
ranges, with cutReason, reactionHold, matchAction, audioCarry and paceFunction.
DRAFT keeps unknown speech boundaries explicit; REVIEWED requires audio/dialogue
review. `picture_edit_handoff` checks current hashes and frozen Canon before a
Host assembly may consume the plan. It never renders or mutates source bytes.
Provider output length is not mandatory final-cut length. Planning picture cuts
is separate from the existing sound-only finishing renderer, whose packet/timestamp
preservation remains unchanged. Do not feed arbitrary picture cuts into that renderer.
The bounded Host assembly in [sequence production](sequence-production-contract.md)
uses reviewed ranges and explicitly re-encodes a new candidate. Retain a derived
Media before formal delivery; original native AV remains immutable.

Finishing cannot rewrite Script peaks. It may carry original source audio across a
picture cut after checking measured speech/action; unknown native singing or mixed
sound is not permission to mute, dub, loop or generate music. BGM is downstream of
story/visual/edit success, never a substitute. Proposed peak/coverage edits remain
offline artifacts unless separately authorized for formal story revision.
