# Film editorial authority

Existing owners remain: Director judges approved meaning; shot-design owns minimal
coverage; cinematic-finishing owns measured edits, FilmReview and local execution.
No additional Skill, Canon entity, Tool or timeline is introduced.

`EditorialRhythmPlan.editorialAuthority` optionally contains an EditorialAuthority:
source-pinned EditorialIntent, shared CoverageUnit references, CoverageRequirement,
CutCondition / EditorialHold and scene EditorialTransition. Units are editorial
functions of identifiable material, not provider job counts or formal Shot rows.
Sharing requires one staging/view actually supplying all named duties. Do not hide
several incompatible views in a single count to claim economy. Each required unit
names the exact lost function if removed; optional units need activation conditions.
`editorial_handoff` validates source pins and gives removal witnesses. Artistic
sufficiency and actual producibility still need review, not a numeric optimizer.

Cut conditions are event-based. `cut_verdict` requires the declared ordered events,
reaction, spatial and audio evidence. UNKNOWN is not completed. It does not observe
media itself. P0/P1 impact returns UPSTREAM_AUTHORITY_REQUIRED; P2 requires explicit
work-grammar equivalence; discard P3 before sacrificing higher intent. No text
label can authenticate a producer's or observer's assertions. Keep evidence refs.
Unspecified listener/subtext/overlap remain unspecified: use approved grouped
reception as grouped authority, never create a new individual reaction.

`FilmReview.editorialUsability` contains source-hash-bound EditorialUsability facets.
USABLE_FULL requires complete functions and passing domain evidence; partial ranges,
bounded repairs and pickups remain distinct. Synthetic fixtures never establish
observed film performance. FilmReview's full AV gates still apply. Planned material
outside approved intent returns OUTSIDE_APPROVED_INTENT /
REQUIRES_ADAPTIVE_DIRECTOR_REVIEW, without adopting it. Retake is an upstream
referral, not a decision or provider retry. Preserve good material with local repair
when evidence supports it; never use score to compensate for missing dramatic cause.

Assembly tests completeness and order before compression. Rough-cut removal records
what/why/surviving intent/priority impact; `compression_verdict` only returns a
candidate when impact is NONE. Fine cut uses measured gaze, breath and action;
it cannot reorder approved dialogue or invent a reaction montage.

`PictureEditPlan` remains the only actual picture range plan. `hosts.picture_edit`
executes bounded native-audio hard cuts. Source hashes, ownership, observation,
geometry and stream limits still apply. Intended J/L, ambience and music handoffs
need measured, authorized tracks and existing finishing recipes; audioCarry text
is not execution. Cropping/retiming are taxonomy labels, not new adapter support.
The editorial authority facet does not grant production permission, user adoption,
or full-film readiness. Explicitly hand off unresolved dependencies before render.

Use `EditorialDecision` to bind each existing PictureEditPlan edit index to scene,
director intent, requirement, condition and source pins, with declared event and
reaction/spatial/audio evidence. `editorial_picture_handoff` composes the existing
picture handoff, refuses premature or stale decisions, and reports missing editorial
requirements instead of claiming full assembly readiness. It returns the unchanged
PictureEditPlan for the existing renderer; it does not synthesize measured intervals.
A legacy unscoped picture plan cannot certify this optional authority's completeness.
`film_review_verdict` consumes dailies facets and refuses completion for synthetic,
partially usable or outside-intent declarations. Actual artistic evidence still
belongs to the observer and the upstream Director, never these pure functions.
