# Film Score Direction

FilmScorePlan is the only new top-level sidecar. ScorePalette, ScoreMotif, SceneMusicDecision, MusicCue and MusicGenerationRequirements are nested values with no independent persistence. Composer Brief is a derived artifact. Plans are pure data. Stable Audio LOCAL is a separate execution adapter; its existence confers no generation permission or production qualification.

Director owns WHY and final artistic authority. music-direction owns score dramaturgy and its review. audio-production/future music adapter owns authorized generation; cinematic-finishing owns actual measured picture conform/mix; Asset/Media own storage and lineage; existing MusicRights owns eligibility. A design conflict uses DepartmentConflict; actual observed audio uses FilmReview/FilmFinding SOUND. Never invent playback evidence in a design run.

Pass A DRAMATIC_SCORE_DESIGN uses causal events. Pass B CUE_DESIGN binds existing Shot/Beat/dialogue/cut refs. Pass C PICTURE_CONFORM is an existing finishing execution, not a FilmScorePlan stage with duplicate actual seconds. Approximate generation duration is not an edit point. Composer Briefs preserve only the cue-local MUST/DO NOT and controlled freedom, never the entire Book as a prompt.

All Scenes reviewed does not mean all Scenes scored. NO_SCORE and DIEGETIC_ONLY require no cue, search, generation or assembly. Music must add information or serve an earned action/release; emotional duplication and premature fatalistic foreshadowing return conflict. Native speech/effort, dialogue ownership and meaningful SFX remain protected. Instrumental is the default; no automatic choir/vocal texture.

Historical verse has its own VocalDelivery DECLAMED_VERSE (MELODY NOT_APPLICABLE). It is never an AI composition lyric. User amendments are pinned separately and do not erase historical source facts or earlier SUNG artifacts. Shared vocal response with no approved lyric may remain realization UNRESOLVED even though its occurrence is historically recorded.

Rights metadata optionally separates composition_rights and recording_rights. Explicit split metadata fails closed when either is missing/unknown. Legacy combined VERIFIED metadata remains parseable and retains its old eligibility path; a new score cue requires explicit composition and master proof. A public-domain composition does not clear the master. TEMP_REFERENCE always fails release eligibility, even with otherwise valid rights.

Use the existing CapabilityRequest/requirement_refs to pin a Composer Brief or MusicGenerationRequirements payload. No provider-specific parameters are accepted. Future qualification must prove instrumental/duration/structure/continuation/revision/motif/reference/stems/lossless/forced-vocal/commercial-rights/prompt/cost capabilities; unknowns block production. The first real provider phase uses one replaceable provider. Nothing here schedules or invokes it.

MusicYieldEvent and MusicYieldPolicy are nested MusicCue values, not new top-level contracts. Existing plans without them remain readable; review_placement rejects missing policies on newly placed cues. The policy expresses ENTER/BUILD/HOLD/THIN/DUCK/DROP/STOP/RETURN/DO_NOT_RETURN, current source pins, protected no-score refs and explicit re-entry. Composer Brief derives this policy when present, leaving prior briefs unchanged.

The existing renderer consumes an optional scorePlacement facet (plan, planFingerprint, current, actionScenes); every BGM layer then needs scoreBinding (planFingerprint, sceneId, cueId, actionRefs). Validation runs before rendering or cache reuse. Proposal plans, stale pins, unbound layers, silence, historical verse and protected actions fail closed. Mixed approach/impact source refs require later picture-conform refinement and cannot authorize an entire BGM layer. This is a semantic gate, not sample-accurate media coverage verification. Legacy recipes without a FilmScorePlan remain compatible: the Host must attach every known plan and cannot strip it to bypass silence. No automatic plan lookup or new service was added.

GeneratedMusicCharacterReview and planned-versus-realized reconciliation are derived evidence artifacts. User content acceptance is hash-bound and is neither placement approval nor adoption. Sound priority varies by event: score can build expectation, then give the collision and breath full attention. NO_SCORE_THROUGH_END is valid.
