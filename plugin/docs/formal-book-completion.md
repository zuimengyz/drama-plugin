# Formal Book completion and range safeguards

Department integration owns the existing R0 packet review and returns DEPARTMENT_REVIEW_READY. Only complete_production_book may return DIRECTOR_PRODUCTION_BOOK_READY_FOR_USER_REVIEW. The Host entry review_formal_book re-reads the configured canonical MemoryProvider twice, from Work to every Script, Episode, Scene and Shot. It supplies an ephemeral source witness, not a caller-supplied list or new DB entity. Persisted-reader test adapters are dependency injection for offline tests, never proposal parsers.

The full gate requires same-source/route readiness, all R0 originals, current SceneDPD and composed LineDPD, DirectorPerformanceIntent, visual and voice projections, all source-derived character/interaction/action/Shot/voice/AV obligations and observable continuity. A full self-review binds hashes of these originals. Narrow department review, an approval label, a shortened manifest or a JSON status cannot substitute. Every formal action sentence is conservatively retained; semantic decomposition and relevant ensemble membership still require the responsible source owner's reviewed annotation. performanceGroups belongs to existing Scene content, not a new psychological entity.

All canonical pins include the stored revision inside content. A different parent, invented Shot, stale fingerprint or proposal DPD fails closed. Source inventory is derived, not a parallel truth store. Host Python services are trusted code; the ephemeral witness is not a sandbox against arbitrary malicious Python execution. Durable replay requires a fresh canonical read.

DPD internalActivation and externalControl retain authority. A Director ceiling is an upper limit, not a required intensity. Visual HIGH does not force voice HIGH. The Director's physicalConsequences map binds an exact source action anchor and permits physical loss of support only after that action completes. Emotional or ambiguous collapse remains separately prohibited.

Book readiness authorizes user review only, never casting, lookdev, freeze, media or provider dispatch.
