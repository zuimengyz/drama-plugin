# Explicit temporal observer reconciliation

`drama_plugin.hosts.temporal_observer.reconcile` is a Host evidence adapter, not a semantic model, new tool, or storage hook. It accepts a neutral ordered-media manifest, visual observation, optional audio observation, and an independently produced factual verification. Invoke it explicitly from the Director review workflow. No `media.create/save` coupling and no generation calls.

The Host first isolates a blind observer with only media, time-indexed samples and neutral instructions. It must not expose source prompts, story, expected actions, coverage meaning or past judgment. A separate verifier inspects the media after the observer completes, confirms fact IDs, retains uncertainty and pins the exact observation hash. The adapter cannot authenticate the reviewer or prove isolation by inspecting prose; the Host retains its input/context and verification receipts. The allowlist detects extraneous fields, not every possible instruction hidden in free text.

Ordered, full-duration window sampling can establish coarse temporal visual facts. Declare `TEMPORAL_VISUAL` in the existing ObservedMaterialEvidence/PlaybackObservation method fields; do not call it normal-speed playback or full audiovisual review. Single stills retain `FRAMES`, which cannot establish action order. Sampling gaps, precise onsets, occlusion and the unsampled tail remain UNKNOWN. Dense samples are for specific unresolved event windows only.

The adapter checks source/frame/audio hashes, ranges, window and sample order, fact evidence, confidence, exact independent review pins and blind-context audit. Unconfirmed facts become UNKNOWN. A sound receipt requires actual audio semantics and independently confirmed time-indexed events. VAD, ASR-only and technical metadata never pass the full audio gate. Audio-to-source offset and stream end must be explicitly verified; coincident timestamps do not establish a causal connection or speaker identity.

The result contains aligned events with unresolved audio where necessary. `TEMPORAL_ALIGNMENT=PASS` means a verified common timebase, not successful audio understanding. Full attestation additionally needs visual, spatial, audio, uncertainty and blindness PASS. Visual PASS with audio FAIL is PARTIAL_CAPABILITY, never full observer validation. Existing NORMAL_AV dailies/adoption gates remain unchanged. No result from this adapter authorizes canonical observation or formal Media: the existing intended-authority receipt is still required.

Convert independently confirmed facts to the existing ObservedMaterialEvidence facet with time/sample references and source-pinned detailed receipt; do not create another observation schema. Host runtime/model versions and extraction provenance live in that receipt. A noncanonical sample must use explicitly noncanonical references and remain outside current Work judgments.
