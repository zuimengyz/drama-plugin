## 影片定位

一个仍能冲破眼前敌阵的人，逐渐失去能与他一起离开的人。他可以命令人冲锋，可以证明自己没有失去力量，却不能让每个亲近者都有去处。最后，真实可用的船到了面前，他仍要亲自决定是否回去。

核心悬问：**当“我还能赢”已无法回答“我们怎么办”，项羽会怎样对待仍在他身边的人，以及仍然向他伸出的手？**

这里没有为他补写一个终于认清全部败因的结论。勇武、亲近、羞愧和固执可以同时成立。

## 人物与关系

项羽：军令依然有力量；亲近的人却会提出不能靠军令解决的要求。他愿意给出力量，不习惯接受照顾；后者是本稿的表演性解释，并非新发现的史实。

虞美人（用户熟悉的称呼为虞姬）：与项羽已有长期随侍关系。本稿不确定她的婚姻身份与最终命运。她要与眼前这个人完成一次共同饮酒，不接受他一边应付自己、一边已经离开的相处方式。她知道包围和歌声，不知道楚地真实归属，也不预知乌江。

楚从骑甲：从正式无名从骑中选出的连续戏剧角色，无新姓名、籍贯或传记。他既追随项羽，也想接住自己的同伴。不是全军的代言人，不能替所有失散者解释去向。

军吏：交出不能再改善的军情，仍须执行出走命令。亭长：带来可以实施的援助，劝项羽活下去。吕马童：旧识，已在汉军关系之中，不补写背叛故事。韩信、灌婴：通过组织应战与追击，持续改变楚军的选择条件。

关系主线：被等待 → 短暂接受陪伴 → 允许同伴相互等待 → 需要同伴见证自己的力量 → 面对再次被接纳的可能，拒绝为自己接受它。

## 故事梗概与读法

垓下，楚军的推进被两翼压迫与汉军再进打断。粮尽，四面传来楚歌。项羽在夜帐中被虞美人留住一杯酒的时间；他唱起自己的力量，唱到她时，歌成为不能作答的问句。她和声回应，二人完成这次短暂相处，未来没有得到解决。

项羽带八百余骑南出。夜路上，一个从骑为掉队者留出归队的空隙；渡淮后，他还在等，项羽最终只给得起短暂停留。陷泽时，众人的互相接应先于继续前行。东城，二十八骑共同投入快战，项羽兑现了自己的能力，得到他们真切的认可。战争仍没有逆转。

乌江有船，亭长仍愿接纳他。他拒绝为自己接受这条生路，却把跟随多年的马交给亭长。最后，他以旧识辨认一个已属于对方军队的人，结束自己的生命。汉军继续行动。

## P01　推进的战线

垓下战场／日。对应正式 S1；CURRENT_FORMAL · RETAINED，压紧动作文字，保留四条对白。

**Scene Purpose：**让一次真实有效的推进败给更完整的军队配合，建立此后败亡的军事原因。

**Action**

楚军向前。汉军前列被迫后退，后排遭前排撞住，旗仍在人群里竖着。

**韩信〔s1-hold〕：**“收住！旗不要退！”

退下来的兵重新靠向旗所在的位置。楚军继续挤进这段让出的土地。

孔、费两军从侧面压来。原先朝前的楚盾不得不转向，转过来的盾又挡住后面的楚兵。有人还在往前，有人已经被迫横着走。

**项羽〔s1-side〕：**“转过来，护住侧面！”

项羽转马，近旁的人跟着把侧面护住。但更远的楚阵已经断开，命令传过去时，那里的人正在向后退。

汉军前列重新站住。侧翼的压力仍在继续。

**韩信〔s1-forward〕：**“进！”

正面的汉兵再次向前。楚军刚刚争到的路窄下去。

项羽挡开逼近的兵器，为近兵留出转身的地方。

**项羽〔s1-retreat〕：**“退回营垒！”

楚兵从他身侧退过。推进停止，撤回开始。

**Silence / Transition：**战斗声不突然消失；省略退回营垒的重复路程，进入战后供粮处。

*入场：观众尚可相信推进能打开局面。出场：项羽仍有局部指挥力，楚军却失去主动。台词行动：止退、护侧、再进、撤军。史料：核心交兵顺序直接支持；阵内具体动作属既有电影改编。建立→P08：个人能力与组织结果将再次分离。*

## P02　空着的粮器

楚营／夜。对应正式 S2 前半；CURRENT_FORMAL · REVISED_PROPOSAL。将报骑数和南出命令移至 P04。

**Scene Purpose：**粮尽与楚歌使营地失去可以继续等待的条件；留下的人第一次成为离开者看得见的负担。

**Action**

军吏倾起粮器，把底下的碎屑赶到一起。面前的碗等着。他停手，碗还没有撤走。

项羽来到。军吏把器口转给他看。

**项羽〔s2-food-q〕：**“还能支撑几顿？”

**军吏〔s2-food-a〕：**“没有下一顿了。”

项羽没有再让他去找。

一名士卒把空碗拿回。身旁的人伸手接，他摇一下头，自己放下。军吏转回身，继续把还没领到东西的人往后疏开。

远处有人唱楚歌。

楚从骑甲停下缠手的布。旁边替他绷紧布条的人没有听清，还在用力；他按住那只手。另一边也有歌声。

营里几个原本各做各事的人，先后朝不同方向转过去。没有人带回新的楚地军报。

**项羽〔s2-song〕：**“汉军把楚地都得去了？怎么有这样多楚人？”

军吏没有答案。项羽站了一会儿，转身走向帐中。

**Silence / Transition：**外面的歌还在。帐里有人已经把酒倒好。

*入场：战败但营垒仍可暂依。出场：粮尽确定；楚地是否尽失仍只是项羽疑问。关系变化：他看见无人可分的粮，军吏无法再用执行换来改善。台词行动：求证、交付坏消息、追问。直接史料：粮尽、闻歌惊问；供粮及缠手动作：电影改编。建立→P04：带骑者离开不等于带全营走。*

## P03　这一杯

楚营夜帐／同夜。NEW_CANON_SUPPORTED_SCENE；具体相处方式为 DRAMATIC_ADAPTATION。

**Scene Purpose：**让项羽暂时停止对外安排，接受一个亲近者对相处的要求；把“如何处置她”改变为“她也能回应我”，不替二人的未来作答。

**Action**

虞美人把酒送到项羽手边。他接住，却没有饮，耳朵还朝着帐外。

她自己也有一杯。她没有举杯等他的命令，把身旁的坐处空出来。

**虞美人〔N01·电影改编〕：**“坐下喝。”

项羽向帐外望。

**项羽〔N02·电影改编〕：**“外面还在等。”

她看了一眼他手里未动的酒，把自己的杯举起来。

**虞美人〔N03·电影改编〕：**“那就这一杯。”

她不往他身前追，也不先饮。他看回她，终于坐下。

项羽喝了一口。听见外面的楚声，又把杯举起来。这一次，他自己的声音进来。

**项羽〔N04·史料引歌，简体转写〕：**

> 力拔山兮气盖世，时不利兮骓不逝。

第一句仍有足以让帐内人抬头的气力。他没有摔杯，没有站起来向谁证明。酒还在手中。

**项羽〔N05·史料引歌，简体转写〕：**

> 骓不逝兮可柰何，虞兮虞兮柰若何！

唱到她，他终于不再看帐外。

虞美人接住他停下的歌声，和唱。她没有替他回答该往哪里去，也没有许下等他回来的话。这里只写“和之”的行为，不另填后世和辞，不声称还原古代曲调。

项羽的眼泪落下来。他抬杯，手停了一下。虞美人仍向着他，继续把这一遍和完。帐内的侍从低下头。

帐外马匹挪动，缰具相碰。项羽的身子已经要起，虞美人的杯还没有饮完。

他停住。

她饮尽，放下杯，自己先站起来。项羽也站起。两人一同走到帐口。

**Silence / Transition：**项羽出去。虞美人此后的去向不在本片展开；不留下独坐、取剑或死亡暗示作为本场句号。叙事跟随项羽，接到待发的骑者。

*入场：他仍在处理外部军情，她拒绝把这次相处缩成单方面安置。出场：他真正接了她的一杯酒，也听见她的回应；未来仍无答案。台词行动：要求相处、提出现实阻力、限定请求、以歌自陈与发问。直接史料支持饮帐中、虞随侍、作歌、和歌、泣；杯、坐起与等她饮尽是本项目改编。建立→P06/P08/P09：被人陪伴、被人见证、被人接纳是不同关系，不重演本场。*

## P04　给后来的人留一点路

楚营出口至重围之外／夜。对应 S3，承接 S2 后半；CURRENT_FORMAL · REVISED_PROPOSAL。

**Scene Purpose：**用真正离开的行动兑现南出，同时让“随我走”遇到同伴想把另一个人也带上的要求。

**Action**

骑者已经聚齐。军吏走到项羽马前。

**项羽〔s2-number-q〕：**“能随我走的，有多少骑？”

**军吏〔s2-number-a〕：**“八百余骑。”

项羽上马。帐前方才还挪着步的骓马，在他坐稳后向前走了两步。旁边没有马的士卒让开。

项羽看见他们。

**项羽〔s2-leave〕：**“随我南出。”

骑队穿出营地。营火仍在留营者身后烧着。

重围的一处间隙里，楚骑接连通过。一个骑者被前面的拥挤隔下，楚从骑甲已经过去，发现身后的人没有跟上。他压住马，没有掉头撞回去，先让身侧空出一条可走的路。

项羽回身，看见这段队伍慢下来。他没有催压。从骑甲等到落后者越过自己，才跟上。

短促的接触留在后面。骑队脱离眼前阻拦，继续南走。

**Silence / Transition：**不把脱出一处写成战胜全部重围。夜路省略，汉军直到天明才发现。

*入场：仍有八百余骑可组织。出场：一批人脱出，留营者没有随之获救；项羽许可了一次实际的等候。对白全部从正式S2迁移，未增台词。骑队南出为直接史料；具体等候与重复从骑身份为电影改编。建立→P06：同一个人还会等，等待条件却会改变。*

## P06　还没有来的人

淮水以南／行程之后。对应 S5；CURRENT_FORMAL · REVISED_PROPOSAL。

**Scene Purpose：**把人数减少变成一次不能无限延长的等待；让同行者的愿望与继续逃行第一次正面相抵。

**Action**

水已在身后。到达的人停下来，马鼻里还在急喘。

项羽扫过这支疏下来的队伍。

**项羽〔s5-count〕：**“后面还有多少？”

**楚从骑甲〔s5-answer〕：**“跟得上的，百余骑。”

他说完仍望着来路，没有把马转过来。夜里被他接回队中的那个骑者，此刻没有出现。

项羽准备动身。

**楚从骑甲〔N06·电影改编〕：**“再等一等。”

旁边的人看向项羽。从骑甲没有再解释。

项羽留住马。他也朝那条路看。

一阵风掠过路边草，后面没有马蹄声。项羽先把马转向前路。这次，从骑甲没有立刻跟着转。

项羽停在原地等他。

从骑甲终于收回目光，自己跟上来。项羽才重新向前。

**Silence / Transition：**留空的是去向，不是死亡证明。队伍离开淮南，省略后续行程，到阴陵附近遇到岔路。

*入场：仍可凭同路相信会合。出场：他只能带走已经来到的人，无法保证还没来的人；从骑甲的个人诉求被听见却未能满足。台词行动：核实、报告、请求延缓。新增等待过程是电影改编；史料只支持渡淮后能属者百余。回收P04，预备P08：同伴后来为他作证，已不是只会复诵军令的人。*

## P07　先退出来

阴陵岔路、随后泽地／日。对应 S6；CURRENT_FORMAL · REVISED_PROPOSAL。

**Scene Purpose：**错误方向消耗逃亡余地，互相接应保住局部行动能力，却不能阻止汉军追及。

**Action**

前路分开。项羽勒马，向田父问路。

**项羽〔s6-road〕：**“往哪边走？”

**田父〔s6-left〕：**“左。”

项羽带人向左。田父留在原地。

行了一段，地面渐软。最前的马失下半步，后面的马还在往前挤。项羽的马也被挤住，已无处转身。

**项羽〔s6-back〕：**“回实地！从后面退！”

最后面的人先向实地退，给前面腾出地方。从骑甲下马，把自己刚让出的空处留给身侧陷得更深的骑者；对方退出来后，又伸手拉住他，让他借力登回自己的马。

项羽没有另闯一条路。他压住马，等撤出的次序来到自己，沿已经让出的地方退回实地。

远处较高的硬地上，汉骑出现。

楚骑尚未收齐，已经不能停留。项羽领他们折向东。

**Silence / Transition：**不解释田父为什么误导；不把几个人的帮助写成全队尽数脱险。继续东行的路程省略，下一场队伍已缩成二十八骑。

*入场：尚试图靠路程甩开追兵。出场：延误使敌军追及；互助仍有用，却只救得眼前行动。台词行动：询路、误导、调整撤出次序。问路陷泽和追及直接支持；具体互助是电影改编。P06只得离开未到者，P07则仍肯为眼前的人腾路，不能把前场理解成人人不管。*

## P08　让他们看见

东城附近坡地／日。对应 S7；CURRENT_FORMAL · REVISED_PROPOSAL，保护原快战因果与五条对白。

**Scene Purpose：**让项羽把个人能力真正兑现给仍在身边的人；他们得到一场值得相信的胜利，战争出路却没有因此恢复。

**Action**

二十八骑停在坡上。汉骑从下方逼近，后续的人马还在赶来。

从骑甲把松开的手布重新勒住。旁边一人替他攥住末端，等他扎牢才放手。项羽望过他们；这一次，他要他们留下看的是自己。

**项羽〔s7-last〕：**“今日与诸君决死。我再替诸君破阵——让你们看，是天亡我，不是我不能战。”

他指向山的东面。

**项羽〔s7-four〕：**“分四队。冲下去，到山的东面会合！”

骑者分开。项羽首先驰下，一队随他直撞眼前敌阵，其余队伍从各自方向冲下。

汉军迎上来。项羽斩倒当前一将，堵在这条路上的兵退开；后面的楚骑就从这个缺口过去。坡上方才攒住的那口气，终于随着奔马吐出来。

楚骑在山东三处会合。尚有人勒不住速度，绕出一小段才转回，互相喊出的都是没有成句的声音。有人抬臂碰一下刚从缺口出来的同伴，立刻又抓回缰绳。他们这一次真的打穿了。

汉军一时不知项羽在哪一处。随后，追军分成三路，分别压向楚骑所在的位置。

刚有的空地又在变窄。

项羽再驰出去，斩一都尉，将身边的追兵逼开。楚骑利用重新打开的空处聚拢。

项羽回到他们面前。他身上仍有刚打完的热气。

**项羽〔s7-how〕：**“何如？”

从骑甲迎着他的目光。方才为自己提出过请求的人，此刻先应声，其他人也应。

**楚从骑〔s7-as〕：**“如大王言。”

项羽笑了。那笑没有被立刻取消。

重新聚起的队中，有两骑不在。余下的人还没歇匀，远处的汉骑已再次向这边移动。

项羽把脸转向东面的路。

**项羽〔s7-east〕：**“向东。”

**Silence / Transition：**保留胜利的快意，再让追军的继续显出它的限度。离开东城至乌江之间有行程省略，不把河岸放在坡脚。

*入场：项羽已判断难以脱身。出场：能力被同伴认可；主动权仍在汉军，余骑仍须走。建立/回收：P01的局部力量不能代替组织；P04/P06中有自我诉求的从骑，现在选择认可他。史料支持四队四向、山东三处、再围再战、亡两骑与问答；甲先答、短暂欢快等为改编。此处是 ACTION PAYOFF，不用帐中歌的重现把它压成挽歌。*

## P09　船在岸边

乌江岸／日。对应 S8；CURRENT_FORMAL · REVISED_PROPOSAL，保留六条对白及真实渡江可能。

**Scene Purpose：**让已经得到能力证明的项羽，面对一次不能用能力证明代替的选择：接受败后仍可获得的接纳，或拒绝它。

**Action**

船已经靠住岸。亭长扶住船沿，等岸上的人过来。

**亭长〔s8-boat〕：**“大王，上船！”

项羽向船走两步，看到对岸。

**亭长〔s8-urge〕：**“江东还有土地、百姓，足可再立大王。这里有我的船；汉军一到，便走不得了。”

他把可以落脚的地方让出来。

项羽的手还搭着马缰。马向前走，他跟了一小步，又停下。

**项羽〔s8-refuse〕：**“我带江东八千子弟渡江西来，如今一个也没带回去。父兄便肯再立我，我又拿什么脸面见他们？”

亭长没有收手，也没有替他认可这个答案。

**亭长〔s8-here〕：**“船就在这里。”

项羽再看那段空出的地方。他身后的从骑还在，江东父兄并不在眼前，不能替他们说是否肯原谅。

他牵马走到亭长身边，把缰绳送出去。亭长伸手时，项羽还没有松。

**项羽〔s8-horse〕：**“这马随我五年了。我不忍杀它，送给你。”

亭长握稳。他才放开，拍了拍马颈，退开一步。马还朝他的方向偏着头，他已从它旁边走过去。

船仍在岸边。项羽留在岸上。

**项羽〔s8-down〕：**“下马，持短兵！”

从骑们下马。有人落地后腿软了一下，用手撑住马背，再把身体立稳。项羽先向来敌的方向走去。

**Silence / Transition：**不出现虞美人的回忆、遗物或幻听；他没有因一个女人已死而“无可留恋”。现时的援手和拒绝必须独立成立。短兵接战承接到终场。

*入场：他已经证明能战，仍拥有生路。出场：他拒绝给自己的未来，却把马托给另一人。关系回收不是“等我”：P03短暂肯接受陪伴，P06肯等眼前人，P09却不肯接受再立自己。他没有完成疗愈。八千子弟之语是人物自陈，不判断现存从骑籍贯。赠马直接史料支持，交接过程与不撤手是电影改编。CHOICE PAYOFF。*

## P10　军队经过的地方

乌江岸近处／接前场。对应 S9；CURRENT_FORMAL · RETAINED。

**Scene Purpose：**让最后选择产生不可撤回的身体后果，终止个人行动，留下仍在继续的军队。

**Action**

汉兵从陆地方向压来。项羽持短兵迎上，逼开身前的一人，另一个方向的压力随即填入。

接战已有一段时间。项羽身上多处受伤，剑还在手中。他调整脚下，站住。

来敌中有一张认得的脸。

**项羽〔s9-friend〕：**“你不是我的故人吗？”

吕马童看见他，转向王翳，指认。

**吕马童〔s9-identify〕：**“这是项王。”

项羽听见。附近的人还在向这里靠。

**项羽〔s9-reward〕：**“汉王悬赏我的头。这份功劳，给你。”

他自刎。身体失去支撑，落下。

**Silence**

不再有项羽发出的命令。

汉军后续的人马仍在进入，接到前面的人，向前行动。

**Ending：**止于此。不加史家旁白、结尾诗、爱情重逢、死后封赏或新的悬念。

*入场：拒渡已发生，仍有实际接战。出场：人物行动终止，军队行动继续。旧识边界不扩大；吕马童没有被写成悔悟或复归。个人死后军队继续是当前正式剧本的结尾表达，不声称这一具体瞬间逐字见史书。CONSEQUENCE / TERMINATION / AFTERMATH。*
