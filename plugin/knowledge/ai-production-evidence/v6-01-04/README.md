# V6-01-04：知识实际应用与离线交接验证

**状态：未采纳的创作候选；无媒体生成。** 当前助手实际读取案例和专业方法，提出下列两案；接口回放用这些已写出的候选验证交接，不冒充一次独立模型创作，也不是正式V6生产准备通过。没有调用文本模型API、视频API、Runtime、生产账本或正式owner存储。

## 1. 问题与只读来源

表达问题：**观众怎样看见街上的亲密关系，同时感到它不依赖雅科夫的注意而存在？** 不新增事件、人物关系或台词。剧本已有青年折返、接帽吻手、雅科夫看一眼；正式分镜出口是他回到工作。8–12秒是本次局部比较窗口，暂以10秒运行编译，原镜13秒不变。

已读V6第一场、全片导演、全片分镜、04-a原画格设计，并实际查看04-a图；[来源哈希](source-receipt.json)。图中雅科夫在左侧暗前景，青年与窗内女人在右侧较亮纵深；它支持内外关系已可见，不能证明摄影路径、进退余量或动作时序。未引入V5。

## 2. 实际检索与选择

检索原句：“希望观众逐渐发现门外发生的事情，公共生活独立于雅科夫的目光”。[发现结果](discovery.json)将可检查词组映射到reveal／coexistence，返回11个候选，顺序不是质量排名。当前助手选择下列3案，真实读取正文与6项共享方法；[阅读记录](reading-receipt.json)保留内容哈希，而不是只记片名。

| 读取的依据 | 本场真正采用的关系 | 没有继承的部分 | 进入的现有字段 |
|---|---|---|---|
| 《玩乐时间》机场误认／多主体注意分析 | 先让公共关系在同画面可见，由青年折返与伸手引导发现；雅科夫不垄断观看 | 不复制笑料，不将全部背景同步做动作，不强制所有平面同样清晰 | CAMERA.cameraPosition／lensIntention；ACTION.actionPhases；PERFORMANCE.physicalExpression |
| 《人类之子》摄影可离开主角注意的制作讨论 | B案由街上动作触发移动；雅科夫看后收回目光，摄影仍留在公共关系上 | 不复制车顶设备、战争事件、长距离跟拍或无缝效果 | CAMERA.movement.policy／pointOfView；EDITORIAL.protectedEvents |
| 《巴里·林登》窗光来源与房间层次 | 同一门／窗／天空关系贯穿起点、途中与终点，脸部受光不跟着摄影机旋转 | 不复制烛光、服装、古画滤镜、精确焦距或灯数 | LIGHTING.sources／directionAndQuality／intensityRatios／constraints |

没有选择《历劫佳人》的危险知情结构，因为当前场面不需要悬念倒计时。《让娜·迪尔曼》的持续时间方法可支持另一种更长停留，但本实验不据此延长整个V6镜头。拒绝也是实际应用的一部分。

## 3. 同一空间中的两案

以下是**本次待预演的关系示意**，不是从单幅图测出的真实尺寸，不改写已选场景资产。C0位于雅科夫朝街方向的右后侧，低于其肩，斜看对面窗口。用既有门洞，不新开窗。工作台位置须与已选环境复核。

```text
                  对面屋内
             女人 W ─ 窗口／浅窗台
                         手
                  青年 G ← 折返路线
       天空 S（街道上方宽大远源，非摄像机灯）
──────────────── 街道 ────────────────
                       门洞 D
              雅科夫 Y     C1   ←仍在门槛内
             工作台       ↗
                         C0
                  棺匠屋内
```

C0与C1均朝对面窗口，Y在画面左缘；实际相机视锥必须复核，示意图不证明通路可行。没有“为运镜把雅科夫移开”的授权。

| 决策 | A：固定关系画面 | B：小幅斜移，随后停留 |
|---|---|---|
| 摄影机起终点 | C0全程固定；略低于肩，平视窗口与伸手 | 同一C0，沿门内空隙向右约半肩宽、向前约半步至C1，仍在屋内；不是穿墙或绕到街上 |
| 主体／焦点 | Y在左侧较暗前景可稍软，右侧青年与女人的手可读；不追求所有脸同清晰 | 固定焦距、窗口焦面保持；平移减弱Y与门框的遮挡，保留左缘身体；真正视差，非数码放大 |
| 0–2秒，暂估 | 青年折返进入窗口关系；由运动中的人物唤起注意 | C0先停；同一青年折返是移动触发，早于Y的一瞥 |
| 2–6秒，暂估 | 接帽、靠近与吻手在固定范围内展开 | 柔和起步、斜移、减速；到接帽／吻手关系清楚时已停C1，不以移动遮掩接触 |
| 6–10秒，暂估 | Y短暂看一眼再回到工作；街上关系仍可被观看 | 同样动作；停在C1，不随Y回头退回，不新增反应特写 |
| 观看收益 | 给观众发现权；亲密、工作和距离共同存在 | 从私人劳动边缘逐渐让出公共空间；摄影的关注长于Y的关注 |
| 代价与选择理由 | 小屏可能看不清吻手，前景可能过重 | 运动可能强调或美化吻手，暴露未知空间；若不增加所需关系，A更合适 |

秒数仅为编译与后续预演的起始估计；接帽和吻手若自然演完需要更长，不要求加快演员。两案不是“保守版／高级版”，本轮没有选定胜者。

## 4. 光源与灯位必须和机位共用世界空间

两案使用同一布光逻辑，避免把明暗变化误当运镜收益。上午天空S在街道上方，为宽大远源；通过门洞照入Y朝街的一侧及上方，室内背向门一侧保留暗部中间调。对面女人在窗口以内，她伸出的手和街上青年受同一天空，身体更深处较暗；既有浅窗台只提供弱反射。深色内墙吸收回填。没有新增实际灯具、窗洞、轮廓灯或浪漫逆光。

这是明确的光源位置与覆盖设计，**不是已验证光照模拟**。现有04-a显示这种大关系可成立，仍不能确认实际天空遮挡、窗口朝向和每帧肤色。C0→C1不改变S、D、W的世界位置；若换角导致Y暗侧更深，这是可以讨论的可见性代价，不自动把灯挪到摄影机背后。

若后续白模／取景验证发现面部或接触不能辨认，先比较机位与既有反射面。反光板或窗外模拟天光只能作为另一个待选制作建议，不能悄悄进入本轮已选资产。原稿未测量灯距、光比、曝光、光圈，所以不补造数字。

## 5. 声音、剪辑与预演依据

既有女人呼喊可留在前镜末／当前折返之前，不重写或生成台词。车轮声继续远去，门内工作声与街道声保持距离；Y收回目光不令街声静音，不加恋爱情绪音乐。下一镜来客在事件后进入既有剪辑组织，不能在本窗口提前重演。

下一步若Host选择实验：读取V6已选人物、HOME／STREET与帽子身份及空间依据；04-a仅提供已完成吻手状态参考，不能直接作为“青年尚未接帽”的起始帧。B需要检查C0、最大遮挡处、C1的视锥及通路；A需要检查固定范围内接帽到回头是否一直可读。可用关系草图和必要白模／动态预演，没必要机械一镜多图。

电影镜头是持续观看事件；关键画格只是代表状态；连续运动是C(t)、人物、光源及声音共同时间；剪辑接点改变观看组织；技术生成单元受模型窗口限制。这里暂以一个10秒单元演示投影，不认定一镜必须一请求或10秒。没有渲染白模、没有生成Animatic，也没有视频证据。

## 6. 从原稿到实际编译：已经验证的部分

[固定原稿](fixed-designs.json)、[移动原稿](moving-designs.json)是当前助手阅读后写出的可讨论专业设计。CAMERA／LIGHTING通过真实 `FormalProfessionalAuthor.design` 的字段校验与投影；其余领域是局部执行说明，不冒充已完成正式全套Performance／Sound采纳流程。

`replay.py` 把这些保留候选返回给现有作者接口，捕获Director与Professional端收到的完整案例正文、方法正文和哈希。这里的ReplayClient明确不是生成模型：它证明入口加载与返回格式可用，不证明专业作者能独立自动选出同样优秀的方案。创作运用的证据是上表、具体机位／灯位原稿及两案不同收益，不能由mock成功替代。

随后实际运行：`PackageReader → OperationResolver.select_unit → ExecutionProjection → SeedanceTargetAdapter → 现有seedance_2生成器`。仅在内存建立离线EXPERIMENT包，不保存正式准备记录，不验证生产准入、不绑定资产、不提交请求。只对当前单镜局部作检查，未验证跨生成单元接缝。

[继承记录](inheritance.json)含sourceRef→IR事实→Prompt字符区间；[A最终Prompt](fixed-prompt.txt)、[B最终Prompt](moving-prompt.txt)可直接读。每案31项执行事实都有文本覆盖；A为1110字符，B为1176字符。摄影机位置、高度、焦点意图、运动触发／路径／结束、光源来源／方向／对比／连续性均保留。`continuityInterpretation`、片名、作者、网址和研究正文不进入Prompt。没有改动生成器或Provider以迎合这次案例。
