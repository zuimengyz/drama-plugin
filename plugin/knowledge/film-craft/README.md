# Film practice by narrative problem

This is an advisory library, separate from Skills. It is neither a shot catalogue
nor evidence that the current Host has screened these films. Each case separates
published scene evidence, attributed filmmaker views and our transferable analysis.
Sources were read on 2026-10-26; scene locators replace invented edition timecodes.

Start with the spectator's problem, not a desired technique. For example:

```sh
python plugin/knowledge/film-craft/find_cases.py --problem public-life --limit 3
python plugin/knowledge/film-craft/find_cases.py --problem memory --limit 3
python plugin/knowledge/film-craft/find_cases.py --query "回应" --limit 3
```

`--problem` matches an exact index tag (repeated tags mean ANY). `--query` searches
the case title/problem/tags and note text literally. Results retain index order;
there is no quality score or recommendation engine. The index lists all tags.
The command returns paths and source locators, not a packet to paste into a Prompt.

Read only the relevant few cases. Compare what each permits the spectator to
notice, what it withholds and what it costs. The Host can reject all precedents.
Retain the query, chosen/rejected ideas and source URLs in existing author context
or support originals. The screenplay, Director and departments then author the
work's own solution. Formal shots and final writing consume those decisions, not
case summaries. No mandatory lookup, reference count, new approval or production
permission follows from this library.

Coverage: opening/public life (Fanny and Alexander, Playtime), transitions and
sound bridges (The Leopard), ensemble blocking and montage (The Rules of the Game),
listening and everyday aftermath (Tokyo Story), spatial uncertainty (Ugetsu),
memory/time (Wild Strawberries, Mirror), subjective account and interruption
(Brief Encounter), offscreen relations, repetition and literary subtext (In the
Mood for Love). AI realization notes are hypotheses, not claims of tested output.
