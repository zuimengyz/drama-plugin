# 1917 / 1917 (2019)

导演：Sam Mendes；摄影：Roger Deakins。

证据：本轮读取公开制作／访谈／机构资料；未重新完整观片。下文方法分析与迁移方案是本库分析，不冒称原导演意图。风格标签是非互斥检索视角。

场面定位：战壕到奔跑的设备交接，以及Écoust夜城。ASC访谈记录了实际设备排练与多次承载交接。British Cinematographer访谈说明夜城先有上空照明弹，再有模拟燃烧教堂的光；预制小模型用移动小光源研究阴影，学校室内也由同一外部光源穿窗照入。

**关系示意（概念，非原片尺寸复刻）：** 上空移动光F → 街道中的人A／建筑阴影；广场火源H → 外墙／窗口W → 室内人物B；摄影C沿街到W附近时，不能把H改到摄影机后方以保持脸部同亮。

**迁移方法：** 沿一条共同时间线记录演员脚步、摄影位置、转弯遮挡、光源状态和注意对象。先用低成本路径试演判断自然行动需要的空间，再决定场景和设备。反向机位保持光源世界位置，允许脸的受光侧改变。

**收益与代价：** 连续经过空间可让人承担行程；代价是节奏后调余地变小、天气与灯光路径耦合。若剪辑能保住所需时间体验，应比较其代价而非默认长镜头胜出。可以利用遮挡接点，但不得把每次技术分段当剧情停顿。

本条不把原片数字化接缝抹去，不要求AI复制器材。未知：本片方案在Seedance的运动保持、光源稳定和接缝效果；原片灯具规模不是新片应抄的参数。
