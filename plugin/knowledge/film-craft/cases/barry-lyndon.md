# 巴里·林登 / Barry Lyndon (1975)

导演：Stanley Kubrick；摄影：John Alcott。

证据：本轮读取公开制作／访谈／机构资料；未重新完整观片。下文方法分析与迁移方案是本库分析，不冒称原导演意图。风格标签是非互斥检索视角。

场面定位：儿子在餐桌问马的室内场面、赌桌烛光场面。Alcott访谈区分了窗外人工光模拟的日景与仅由烛火照明的段落；不能把全片概括成“只有自然光”。餐桌场面选择一个主要窗口方向，使桌面聚光而周边较暗。赌桌上方的金属板也产生反射作用；极浅景深带来对焦困难。

**相对关系：** 日景：窗外光 → 窗口扩散面 → 桌边人物／桌面，房间周边逐渐暗下去。烛光：桌面及上方火源与面部的相对高度影响眼窝、下颌和背景分离。以上来自采访的关系，不提供未核实的逐镜灯图。

**迁移到当前空间：** 先选择人物应该与哪部分环境共处，再决定主光的来源、有效面积、方向、覆盖范围及反射。摄影换侧后，保持窗口在世界中的位置，不复制上一帧的屏幕左侧亮脸。人物靠近或远离光源时，受光变化是动作的一部分。

收益是让人物与室内空间形成共同的明暗秩序；代价是低照度、浅景深可能限制可见行动。可以选择更深景深、较宽的模拟光源或剪辑覆盖，前提是保住所选关系，而非仿古画外观。无原片灯图全量核验，无AI实测。
