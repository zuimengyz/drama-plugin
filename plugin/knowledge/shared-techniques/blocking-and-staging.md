# 共同时间里的身体与空间

先列各人的真实任务、朝向、能看见／听见谁、身体和道具占用范围。为进出画、穿越、递接、停等选择实际原因；群众不是一起等待主角完成动作的背景。

固定镜头也能内部重构：A退到后层，B进入空位，C从前景穿过短暂遮挡；观众通过持续世界理解关系，而不是靠摄影机忙碌。多主体可同时行动；哪些必须先后发生由物理和人物关系决定。

在共享地面示意中分别标人物路径和摄影路径；在关键时刻核对视线目标、道具持有者、支撑、左右手是否真的必要。遮挡不是删除：说明被挡的人继续做什么，重现时状态是否合理。复杂接触交给Action，不由摄影改人物位置来美化画面。

表演时间包括接受、没听见、继续任务和不回应；不能把“克制”落实为统一无表情。不要为了证明心理存在强加停顿、呼吸或转头。摄影与灯光决定微小行为是否能被接近，不能替演员发明关系。

出处：[玩乐时间](../film-craft/cases/playtime.md)、[让娜·迪尔曼](../film-craft/cases/jeanne-dielman.md)、[人类之子](../film-craft/cases/children-of-men.md)。迁移的是协作方法，不复制原片事件。

执行边界：上述是设计能力；没有当前项目真实视频，不得宣称模型已经实现。
