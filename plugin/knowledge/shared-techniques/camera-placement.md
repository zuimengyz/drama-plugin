# 机位、距离与观看权

先写观众与人的关系：同处、窥见、被排除、伴随或独立观察；不是先选“电影镜头”。

以人物面对方向、门、窗、桌为世界参照，说明摄影机在哪一侧、相对眼睛的高度、距近人与远人的关系和观看方向。低于眼睛不等于强势；近距离也可能压迫而非亲密。主观视点需要人物位置和前后声画支持，过肩并不自动代表认同其立场。

新场面设计练习：C在门内，A近前景，B在对街窗；保持C不动，分别试A完全挡住B、部分遮挡、两人分离。让A动作改变可见关系，再比较C横向移动获得的视差。必要时取关键帧，但不能靠两个终态代替中间路径。

对话可保持双人景，也可过肩、反打或独立听者景。每次改变距离，说明丢失了谁的存在、哪种环境声仍维持关系。反打保持世界位置与视线目标；有意破坏方向可成立，但需要解释观看收益。

迁移出处：[东京物语](../film-craft/cases/tokyo-story.md)、[让娜·迪尔曼](../film-craft/cases/jeanne-dielman.md)。用户对话视频的12种分类只提供选择词汇，不采纳“仰拍=强势”的固定意义。以上练习不是原片机位测量。

执行边界：上述是设计能力；没有当前项目真实视频，不得宣称模型已经实现。

## 对话覆盖教学的转化

[十二种镜头教学](../film-craft/teaching-materials-20261028.md)用于提出选择，不是覆盖清单。双人画面保留回应共时性，反打选择谁能被观看，过肩留下双方距离同时遮住部分空间；细节暂时撤走脸部信息。先决定这种损失是否服务当前对话，再选择高低、远近和切点。
