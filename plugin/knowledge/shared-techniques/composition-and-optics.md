# 纵深、遮挡与光学选择

空间透视来自观看位置。比较焦距时分清“原地换焦距”与“为保持人物大小而移动摄影机”；所谓空间压缩不能只归因于镜头名称。景深受焦距、光圈、对焦距离、成像条件与观看标准共同影响，模型Prompt中的数字不保证物理实现。

前中后景可以同时可辨，注意却不必平均。让动作、轮廓、反差、声音或时间关系决定观众何时接近哪一层。画中画须先有可信的门窗方向；负空间可以保留等待和缺席，不必安排某人来填满。

焦点转移先确定焦点对象A到B、可见触发与转移结束时的观看关系。比较不拉焦而由人转身／退出遮挡，以及剪辑到B。拉焦会暂时剥夺另一层细节；不要把每次注意变化都改成焦点动作。

调度检查：最近身体是否过大到吞掉重要背景；背景清晰是否反而抢走听者；反射面是否把摄影机或不该出现的空间暴露。灯光要让所需形体分离，却不必把所有对象照亮。

出处：[公民凯恩](../film-craft/cases/citizen-kane.md)与[玩乐时间](../film-craft/cases/playtime.md)支持纵深和注意问题；光学关系是基础设计说明，非原片逐镜参数或模型保证。
