# 明暗层次、材质与运动连续性

光源、表面与观看方向共同形成画面。冷暖不是情绪标签：先确定天空、灯、火与反射各自来自哪里，再决定人物怎样进入这些区域。肤色、衣料和木材要保有各自反射，不能统一染成某种“电影色”。

前景暗、中景可辨、背景亮可以形成距离，但也可能遮掉关键行为；反过来把背景压暗可集中注意，却减少世界独立性。每个选择说明作用和损失。深黑、柔和中间调、硬边轮廓都可能成立，不把写实或自然光当唯一标准。

机位移动时，反射高光可能改变，光源世界位置不变；人物转头后受光面积改变是正常结果。换反打应从同一窗、灯、墙面重新推导，不粘贴“左侧光”。夜景窗光、实用灯与背景可不同色，调色不能补造不存在的照明来源。

在当前设计中，把source方向／有效面积放Lighting，把表面与空间放World，把色彩发展放Color；Production Design协调矛盾，不写第二份灯光原稿。运动经过亮区可改变观看，但不应仅凭情绪突然换灯。
