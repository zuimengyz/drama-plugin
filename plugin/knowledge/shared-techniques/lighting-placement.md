# 机位—人物—光源联合布局

来源摘要：ARRI手册把主光、辅助光、轮廓光、背景光作为作用分类，轮廓光并非必须；有效发光面积影响阴影软硬。Alcott访谈显示窗光可由窗外人工光模拟，不能把动机与实际器材混为一谈。

以下是当前场面的设计方法，不是某片灯图。先画C摄影机、A人物、W窗、P场内灯、B背景；按世界方位写光源相对A的方向、高度、距离和范围。正面／侧面／侧逆／逆光是光与人、摄影方向的关系；摄影换侧后屏幕受光侧可能改变，而灯不应凭空跟过去。

示意：W窗外大面积源 → A在窗内；C在A后侧向W看；B是更深室内。A近窗时轮廓可亮，面向屋内的一侧主要靠墙面反射。若需要看清表情，可调整C或选择已有浅墙反射；若增设反光板须标为候选制作手段。暗侧的黑布／吸光面减少环境回填；遮光旗限制照射范围，不能写成“黑色灯”。

顶光要核对眼窝和手的可读性；低位火光要解释向上阴影；近处小源容易产生明显衰减，大面积远源不能机械套点源衰减计算。软光不等于平光：方向、反射与负补光共同决定明暗。背景是否需要独立光由所选关系决定，拒绝自动三点布光。

人物或摄影运动时，在起点、中途最难处和终点检查光区、反射、阴影方向；有意变化可以保留。灯位的存在比“漂亮光影”更可执行，未知功率和光比不填伪精确数值。
