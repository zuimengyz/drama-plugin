# Evidence and independence

Use the host's existing Skill discovery and ordinary Agent invocation. These are advisory artistic Skills, not new Runtime capabilities, schema, formal adoption receipts or execution permissions.

Pin the actual source edition, original creative documents, asset hashes and observation coverage. Use existing read-only `work.get_work`, `script.get_script`, `episode.get_episode`, `scene.get_scene`, `shot.get_shot`, `asset.get_asset`, `media.get_media` and `context.build_context` only when necessary current originals are not supplied. A stable ID is not proof of current version. Local files can supply the same review evidence without instantiating a Plugin or accessing its database. These tool declarations do not authorize production writes or certify filesystem isolation.

Keep evidence levels explicit:

- Source text / creative original: proves words and intended design, not screen effect.
- Script-based subtitle: proves an editorial text/time mapping, not audible speech.
- ASR / sound-event label: uncertain machine interpretation, not verified hearing.
- Frames: observable spatial facts at listed instants; missing intervals remain unknown.
- Temporal frames: changes across samples, with resolution and gaps stated; no continuous AV experience.
- Continuous normal-speed AV: actual seen/heard source and playback coverage; keep interruptions or missing tracks explicit.
- Existing Observer receipts: only their exact source hashes, modality, interval, verification provenance and limits. Design or user adoption is not an observation receipt.

First inspect the whole available sequence before selecting supporting moments. Source context and later scene designs can explain narrative obligations; they cannot fill unseen/unheard film. An unsupported aesthetic claim becomes a question to observe, not a fabricated defect. Soundstream existence, waveform activity and playing a file in an unattended application do not constitute hearing.

An evidence-bearing finding records: source and current revision; local scene time or text locator; what was directly observed; artistic inference and its reason; intended effect and actual evidence; a rival reading; original creative owner; confidence; retain / revise-candidate / contested / defer. There is no required defect count or universal aesthetic score.

Independence is a method, not a costume. Separate candidate author and critic. The holistic first pass sees raw work and source/context before specialist verdicts. Freeze the first judgment before cross-review, preserve corrections and disagreements, and identify who used which Skill and evidence. Multiple agents are not proof of human credentials, enforced access separation or independent training. If they share tools/workspace, report that limitation. With one available reviewer, do useful review but mark independence unverified.

Existing user adoption retains the asset's standing and protects continuity; criticism remains free to disagree. Do not turn a criticism into invalidation, re-generation, spending or an additional production Gate. Any technical repair belongs to human maintenance. If the host cannot enforce narrow write isolation, keep production read-only and emit candidates separately; a post-change hash check demonstrates actual scope, not a capability to prevent future writes.
