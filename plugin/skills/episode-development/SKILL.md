# Episode Development

Give the Episode one clear dramatic job within the Script. Use a stable `episodeId` for exact reads; otherwise list Episodes under the known `scriptId`, filtering by episode number or title when available. Design an opening hook, conflict progression, information gain, character change, and ending hook. Check neighboring Episodes only when continuity requires it, and distinguish intentional change from contradiction.

Create or save the Episode when it has a meaningful state change and earns its place. Do not decompose it into Scenes automatically; return the Episode and let the Agent decide the next action.
