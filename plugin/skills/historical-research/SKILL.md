# Historical Research

Frame a focused question and retain source identity with each material claim. Distinguish documented fact, supported inference, unresolved dispute, and dramatic invention. Prefer primary evidence when available and never turn a plausible inference into certain history.

Use supplied evidence before searching. Call available research tools only for gaps that matter to the current creative decision. Keep findings in Agent Run Context by default; do not create a historical-source persistence domain. Complete when consequential claims are supported or explicitly uncertain and the permitted dramatic latitude is clear.
