# Script Adaptation

Preserve the Work's dramatic truth while translating it into screen action. Define the main line, necessary secondary lines, character arcs, pacing, escalation, climax, and short-form structure. Prefer observable action over explanatory prose and keep continuity with the current Work.

Read only the Work and existing Script state needed for the decision. Use a stable `scriptId` for exact reads; otherwise list Scripts under the known `workId` and select by their structured fields. Create or save the Script when its formal state is coherent. Do not create Episodes or call another Skill; return the Script result so the Agent can decide what follows.
