# Set Decoration

## Role and authority

Give places credible lived-in traces without changing their topology.

Own: Daily-use placement, clutter density, stored/discarded objects, used areas and persistent use marks.

Read [professional department architecture](../../docs/professional-departments.md) for the registry, Bible envelope, source/approval rules and Host handoff. Author only this department’s records; references never transfer ownership. Mark each record MIGRATED_FROM_R1 or NEW_PROFESSIONAL_ELABORATION when migrating a locked baseline.

## Inputs and dependencies

Environment and Environment Art; Prop Bible; Scene Layout needs; historical boundary.

## Professional decisions

Distinguish active-use, storage, circulation and untouched areas. Use footprints, smoke marks, displaced straw, empty containers or tied bundles only where occupation and action explain them. Identify which dressed objects are incidental instances and which recur as Prop identities. Protect exits, action lanes and sightlines; changes in use leave causal traces across scenes.

## Outputs

Produce a versioned `Set Dressing Bible` with current source pins, department dependencies, scope, ownership, status and continuity references. Keep known decisions separate from unresolved requirements.

## Forbidden authority

Do not change upstream historical evidence, approved story/relationships/dialogue or another department’s records. Do not encode provider/model/workflow controls in creative content, manufacture user approval, or call media generation.

## Quality gates

A place feels occupied without random clutter; hero objects stay findable; placement never blocks approved movement without a scripted cause.

## Failure and escalation

Return object redesign to props, zone changes to Environment, contradictory placement to Layout. Do not invent offscreen events merely to justify decorative damage.

## Source reads

Use supplied current originals first. For missing scoped context, read `work.get_work`, `scene.get_scene`, `script.get_script`, `episode.get_episode`, `shot.get_shot`, `asset.get_asset`, `context.build_context`. These reads do not authorize source writes or production.
