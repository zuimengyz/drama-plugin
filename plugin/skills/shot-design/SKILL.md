# Shot Design

Cover the Scene's dramatic turn with the fewest necessary Shots. For each Shot, specify framing, camera position, composition, blocking, action, expression, camera movement, dialogue coverage, duration, and entry/exit state. Preserve spatial, performance, prop, wardrobe, and temporal continuity.

Use a stable `shotId` for an exact read. With a known `sceneId`, list Shots and apply structural filters; when only a natural-language shot description is known, search Shots and scope the search to the Scene when possible. Judge search candidates before revising coverage. Create or save a Shot only when it has a clear dramatic and visual function. Do not resolve assets or produce media automatically; return the designed Shots for the Agent's next decision.
