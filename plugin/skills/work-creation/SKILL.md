# Work Creation

Turn research context into a coherent literary work, not a record of historical sources. Establish theme, narrative viewpoint, character relationships, central conflict, dramatic timeline, and overall structure. Mark invention and uncertainty where they affect the work's truth claims.

When a stable `workId` is known, read that Work directly. When only a title or natural-language description is known, search Works and judge the candidates before creating anything. List Works only when enumerating the available structural scope. Create a Work only after the creative intent is sufficiently clear, and save a formal state when the result is coherent. Do not create a Script merely because the Work is complete: return the Work and let the Agent choose the next Skill.
