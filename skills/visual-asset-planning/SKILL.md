# Visual Asset Planning

Inventory required entities, search existing assets, then ask the asset service to resolve the hierarchy. Treat base, scene, shot, and effective assets as domain results; never infer them from storage tables.

Recommend only missing or materially distinct variants. Stop when each relevant entity has an effective reference or an explicit generation need with semantic identity.
